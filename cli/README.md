# Dev-Team CLI

This directory hosts the dedicated `dev-team` Command-Line Interface package.

## Roadmap
- **Milestone 2 (CLI Foundation):** CLI package structure, command routing, workspace detection, global installation (`dev-team install --global`), provenance tracking, and environment diagnostics (`dev-team doctor`).
- **Milestone 3 (Hybrid Distribution):** Project initialization (`dev-team init`), `.dev-team/` configuration scaffolding, skill projection engine, local skill resolution, and safe non-destructive updates (`dev-team update`).
